8.1 Browser

BROWSE, or push SAMPLE on SAMPLE.
Launchpad: Session + up.

Folders and WAVs on the card, and projects in /projects. Resting on a WAV for a moment plays it. Picking a sample from BROWSE asks where it goes. MODE or BROWSE closes.

KnobSettingTurnPush
1FILEMoves through the listOPEN a folder, or pick a WAV or project. Shift + push goes UP a folder
2LISTA page at a timeUP a folder
3-DELETE the project file picked (asks first; only from BROWSE)
4PROJECTNEW: start an empty project (asks first)
8-CLOSE

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.2 Naming

SAVE for the first time, or Shift + SAVE; also NAME, DEVICE, ARRANGE's renames.
Launchpad: Shift + Session.

Text entry with the knobs.

KnobSettingTurnPush
1CURSORMoves along the name
2LETTERChanges the letter at the cursor
3-DELETE the letter
7-CANCEL
8-DONE

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.3 Question

Deleting a slot or project, starting a new project, placing a sample.
Launchpad: the same.

Asks first, with CANCEL picked, so pushing twice by accident never deletes anything.

KnobSettingTurnPush
1ANSWERPicks CANCEL or the actionOK: does what's picked
8-CANCEL

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.4 SLOTS

EDIT.
Launchpad: Mixer + left arrow.

Every slot in the project, whether a kit plays it or not, with what plays it.

KnobSettingTurnPush
1SLOTMoves through the listGO TO it: selects it and shows its pages
2LISTA page at a time
3-DELETE the slot (asks first)
4-NEW slot
8-CLOSE

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.5 Inputs overview

KIT.
Launchpad: Mixer + up arrow.

Everything the live kit plays from one device: the keyboard strip shows which keys are taken, the list below names each. KIT or MODE closes.

KnobSettingTurnPush
1DEVICEWhich device is shown, or ANYRenames the device
2ASSIGNPicks an assignmentGO TO IT: shows its slot
3TARGETChanges which slot the picked assignment plays

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.6 CCS

Shift + LEARN.
Launchpad: Mixer + Session + down.

Every controller CC bound with LEARN, what it sets and its value. A bound setting shows a CC tag on its column. LEARN or MODE closes.

KnobSettingTurnPush
1CCMoves through the bindingsShift + push removes the one picked

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.

8.7 SETUP

SETUP.
Launchpad: Mixer + down arrow.

Device settings, kept on the card apart from any project. SETUP or MODE closes and saves them.

KnobSettingTurnPush
1PHONESHeadphone level (the codec's)
2SCREENBacklight brightness
3MEMORYShows sample memory in useFREE UNUSED: frees samples nothing plays, after stopping everything
4STRESSRUN: the 30 second stress test, showing audio CPU

Knobs not listed do nothing here. Shift + push puts most settings back to how a new one has them.
